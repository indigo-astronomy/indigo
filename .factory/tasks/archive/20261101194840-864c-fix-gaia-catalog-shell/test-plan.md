# Regression strategy
Use synthetic tiny Gaia CSVs and the actual parser, with no production catalog/index download or allocation. AC-001/004: a literal shell-looking directory that the old popen evaluates must fail the baseline expectations and parse correctly after repair; assert harmless sentinel absent. AC-002: spaces/newlines and punctuation in names, visible .csv selection and deterministic order, parsed-coordinate controls. AC-003: missing/non-directory and overlong paths fail; empty-directory behavior explicit, ownership checked with sanitizers when available. AC-005: relevant existing tool tests, configured Factory check/test/security groups, final diff review, finding integrity and committed process validation. No shell_compliance/protected drivers/hardware; no Windows/Linux pass claims on macOS.
