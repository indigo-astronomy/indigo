## Confirmed candidates for coordinator registration

All candidates below are nonblocking for accurate audit recording, remain open product issues, and have high confidence for their stated scope. No generator change or owner risk acceptance is inferred.

1. **Property CLI file upload reads from EOF** — medium functional. `indigo_tools/indigo_prop_tool.c:93–107` obtains length with `indigo_uni_seek(handle, 0, SEEK_END)` then immediately reads that length without rewind. The actual portable seek implementation (`indigo_libs/indigo_uni_io.c:2287–2304`) calls `lseek`/`_lseek`; the descriptor remains at EOF. Thus nonempty `set_script ... SCRIPT=file` and write-only BLOB uploads fail through `read_file()` with -2, and that failure branch returns without closing the handle. This is distinct from RAW-to-FITS FND-000039. Minimal remediation: check seek/representable size, rewind, guarantee close on all paths, terminate script text, exercise nonempty script/BLOB file success and failed-read cleanup. Source-contract proof; no network upload attempted. Owner: coordinator/tool maintainer.

2. **Generator stalls on unknown DSL bytes** — medium functional. `indigo_tools/indigo_generator.c:340–411` has a tokenizer loop whose recognized alternatives advance `current`, but no fallback advances/rejects an unknown byte. Temporary compile of exact unchanged source with `cc -w /Users/polakovic/Development/indigo/indigo_tools/indigo_generator.c -o TEMP/generator` exited0. In an isolated temporary directory `generator input.driver`: valid `driver audit { version = 1; aux { name = "Audit"; } }` exited0 and generated three files; `driver audit { @ aux { name = "Audit"; } }` hit Python subprocess timeout after1second. Files and binary automatically removed. This hangs a normal erroneous definition/build; the editor limits generator wall time but direct Makefile use has no such recovery. Minimal remediation (requires separate explicit generator-diff approval): reject unsupported token with position; add malformed-token/unterminated-input tests. `match()` at426 also accepts `driverXYZ` as `driver`; exact synthetic input `driverXYZ audit { aux { name = "Audit"; } }` exited0. Treat strict keyword matching as related parser hardening, not a second severity inflation. Owner: coordinator/generator maintainer.

Both scripts are installed by Makefile272–273 and server Wi-Fi infrastructure requests call the installed helper (indigo_server.c:1544). An exact-function synthetic probe extracts `__ALERT`, `__OK`, `__set-wifi-client`, replaces only external commands/config paths with temporary fixture files/stubs and disables sleep. Password `x`: legacy exits0/stdoutOK, logs command-not-found, writes psk="x" and invokes stub disable/reboot; v2 exits0/stdoutOK and calls stub `con down`, `con delete`, `dev wifi connect test password x`, modify/up. No real network/service/reboot was used. Initial probe extraction was invalid because it stopped at the WPA heredoc closing brace (syntax error); corrected extraction ends at function close before next comment banner. Minimal remediation: invoke alert before any destructive config/connection mutation and test both length boundaries/valid controls. Owner: coordinator/Sky maintainer.
