# Regression contracts

Derive expected behavior from specification and retained audit, not implementation. Transport: small malformed/negative/overflow/duplicate lengths; empty/valid/over-limit body; short EOF/read error; stalled body; concurrent cache lookup/retirement/publication; preserve old data after failure. Parser: exact and over-boundary attributes/names/entities/tokens; inbound response verbs; declared/decoded BLOB mismatch and multiple items with growth; truncated/masked/oversized WebSocket frames and valid control/data messages. Management: unknown/injection-like item names rejected, canonical choices one argument, percent-containing ALERT literal.

Use synthetic data, socket pairs or isolated fixtures, ASan/UBSan where supported, no floods or large-memory exhaustion, no hardware/helper side effects. Record baseline reproductions when practical and exact source-current build/run commands in developer reports and verification.md. Existing stale build artifacts are not proof. Linux/Windows execution is unavailable unless discovered otherwise; record limits. Coordinator runs configured Factory check/test/security and process gates in addition to application checks; they do not prove application memory safety.
