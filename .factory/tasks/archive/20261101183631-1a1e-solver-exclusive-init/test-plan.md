# Test plan

Non-interactive, hardware-free validation. Capture current relevant suite pass counts before source changes, then demonstrate new reciprocal exclusion scenarios fail on baseline. Real driver registration must be used: direct unregistered INIT alone cannot prove the registry contract. Both agents must initialize under controlled prerequisites so a missing executable cannot produce a false-positive conflict failure. Verify active agent survives rejected INIT and no second agent properties/cache are created, repeated initialization, inactive registration and unload/retry in both directions.

Rerun updated native suites and loader unit regression on changed candidate. Run sanitizer/strict build where the existing make targets support it. Final per-driver runner must be scoped to local synthetic/fake-executable suites, with no remote downloads or hardware. Record exact commands and machine-readable results in task evidence. Factory checks/test/security and committed-range process check are required. No cross-process or arbitrary concurrent raw-loader guarantee is claimed. Product and task diff receive independent source review; root verification/security is sequential and disclosed.
