## Prior candidates and rejected suspicions

- Catalog dynamical-time array warning: **disproved for public finite-date dispatch**. Only JD in [2312752.5,2448622.5) reaches table interpolation. Its computed i is 0..185, so i+2 <= 187 < TERMS(192). The defensive clamp would be wrong for an unconstrained internal caller, but that caller does not exist. Do not file the analyzer warning as an actual out-of-bounds defect.
- FFT sizeof warnings: **disproved**. Arrays are complex double pairs; 2*n*sizeof(double) is the intended byte count. No redundant wrapper/removal recommended.
- PSF background_count division warning: positive radius and valid supported ROI produce 8*radius border entries. General zero/invalid-radius and geometry boundary handling is now classified in FF-06, not a standalone unconditional divide-by-zero finding.
- PSF-map failure propagation: **confirmed** as part of FF-07; renderer must not consume failed PSF outputs. STAR type/digest errors are not generic incoming numeric validation.
- FITS dead-store warning at extension_length -= 9: **not a useful standalone defect**. The actual size/header-capacity failures are FF-05.
- Raw contrast with every pixel masked is **confirmed FF-18 / FND-20261023101753-bc8d-complete-repository-audit-032**: real_count becomes zero, and ordinary saturation masking plus agent_imager.c:948,1695 propagates NaN because the caller checks only ==0. Repair must define/handle an explicit no-valid-samples result; it is no longer an undecided candidate.
- Polynomial nonpositive coefficient counts/zero tolerance and generic helper null pointers: public caller preconditions are not comprehensively documented. Current ordinary callers supply bounded valid values. No fabricated reachable driver defect is asserted from arbitrary misuse alone.
- TIFF seek beyond logical EOF can expose an uninitialized gap on read; actual CCD call is a writer. A general reader contract would need zero-fill and overflow/offset validation; no hostile TIFF decoder finding is claimed for a writer-only integration.
- DSLR reversed-row binning would access row+1 after the last row in the disabled alternative branch, but the public header fixes forward order and current call passes binning=false. **Inactive candidate**, not current runtime defect.
- LibRaw initialization is **confirmed FF-19 / FND-20261023101753-bc8d-complete-repository-audit-033**: the retained LibRaw C API catches std::bad_alloc and returns NULL (libraw_c_api.cpp:30-41), while indigo_dslr_raw.c:150-153 dereferences raw_data->params. Guard initialization and cover ordinary allocation failure; no malformed-image exploit claim.
- DNS-SD callback errors are **confirmed FF-17 / FND-20261023101753-bc8d-complete-repository-audit-031**. Installed Xcode SDK dns_sd.h Browse:1677-1681 and Resolve:1792-1796 explicitly leave other fields undefined on nonzero errorCode, but browser_callback:402 and resolver_callback:361 consume them. Guard errors first, retain requested-name context and add fake callback error fixtures; no service probing.
- Unified I/O legacy indigo_printf uses vsnprintf's would-have-written length against a fixed buffer. **Confirmed FF-16**; current unified formatter reallocates correctly, but public legacy callers can exceed the old buffer.
- Nutation accumulator reuse is **confirmed FF-20 / FND-20261023101753-bc8d-complete-repository-audit-034** at indigocat_nutation.c:183-219. Changed-date recomputation adds the prior degree result before division by36,000,000, causing a tiny history-dependent error. Reset accumulators and verify changed-date/fresh-state consistency. Its low priority and numerical scale do not imply astronomical precision certification.
- Catalog example analyzer include failure: **disproved as a source defect** through its own Makefile include paths. Its sample has no assertion oracle, so printing planets is not validation of astronomy accuracy.
