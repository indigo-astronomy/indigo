# Audit evidence strategy

AC-001/002: tracked inventory and per-component review ledgers with requirements/call paths, reviewed revision and exclusions. AC-003/005: candidate dispositions and canonical findings check. AC-004: configured Factory check/test/security, decision index, targeted synthetic regressions for pending candidates, retained native/analyzer/editor/generation results only when matching sources remain unchanged. AC-006: independent coverage/diff challenge, archived link/registry integrity and committed-range process check.
No product behavior change is planned, so no implementation-mirroring test or hardware suite is required merely to produce audit evidence. Failing diagnostic checks remain findings; mandatory configured checks must pass.
