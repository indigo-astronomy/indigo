## Scope and baseline

Preserve generic PTP and Canon, Nikon, Sony, Fujifilm and Olympus/OM System behavior, including the lens-focuser logical device. Do not change README files. Preserve the pre-existing MIGRATION_STATUS.md working-tree edit.

Baseline: macOS arm64 host, 2026-09-15. `make -C indigo_drivers/ccd_ptp` passed (existing targets up to date). Version before refactoring: 0x02000023. No driver-specific automated tests or simulator exist. Linux build/runtime is unavailable on this host.

## Architecture and audit

The hand-written shared C driver is compiled directly with libusb on Linux and included by Objective-C wrappers using ImageCaptureCore on macOS. Vendor adapters supply initialization, property conversion, exposure, live-view, camera lock, AF, zoom, host-time and relative lens-focus functions. Camera identity uses USB path and the model table; capacity is four cameras. No generator source exists and none will be added.

Public properties include standard CCD metadata, exposure, streaming where supported, preview, upload/native image format, read-only sensor geometry, DSLR deletion/mirror-lockup/GUI-lock/AF/zoom/host-time, dynamically decoded vendor properties, and an optional relative lens focuser. Audit names/counts/visibility against PROPERTIES.md; retain standard names and require X_ for custom additions.

Property work currently uses zero-delay timers. message_mutex serializes some but not all controls. Exposure/live-view functions block for their entire operation; events run independently on timer/ICA callbacks and USB transactions use usb_mutex. Disconnect sets abort and spin-waits for message_mutex before closing. A mechanical timer-to-queue replacement would deadlock event-dependent acquisitions and queue abort behind indefinite streaming. Dynamic property requests share one mutable message_property_index, so queued requests can target the wrong property. Focuser abort performs transport I/O on the bus callback. Arrival/removal handling is not serialized on one driver queue, and libusb events do not retain references before asynchronous arrival dispatch. Shutdown/failed initialization and detach ordering require resource audits.

Repository protocol references: PTP operation/response/event/property declarations and vendor adapter implementation, driver README ISO15740 reference, model table, ICA delegate transport and libusb transport. No fake SDK currently exists. Test the actual PTP transaction boundary, not a replacement vendor implementation.
